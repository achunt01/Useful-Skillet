# useful-skillet

A working collection of Palo Alto Networks reference material: baseline configs, assessment notes, troubleshooting gotchas, and field notes pulled from real client engagements and lab work.

Not an official Palo Alto Networks or Iron Skillet repo. This is a personal knowledge base for building, hardening, and troubleshooting PAN-OS and Panorama environments faster.

## What's in here

- **Baselines** - security baseline references and checklists built from Iron Skillet, PANW Best Practice Assessment (BPA) findings, CIS Benchmarks, and PAN-OS best-practice docs.
- **Assessments** - notes and templates from BPA reviews, health checks, and pre-sales network/security assessments.
- **Gotchas** - things that broke, misconfigs that weren't obvious, and fixes that aren't well documented elsewhere.
- **Configs & snippets** - CLI/XML snippets for zone protection, security profiles, decryption, logging, GlobalProtect, and HA.
- **SD-WAN & Prisma Access** - onboarding notes, policy review points, and lab findings.

## Why

Palo Alto documentation is scattered across docs.paloaltonetworks.com, LIVEcommunity threads, KB articles, and vendor PDFs. This repo is a single place to keep what's actually useful day to day, in a format that's fast to search and easy to reuse across engagements.
